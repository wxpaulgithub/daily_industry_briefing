# 国内行业资讯：来源与质量优化（2026-10-09）

国内 Tab 用于了解仓储、物流装备和相关工业技术。中标结果、已交付项目、产品技术、展会及政策均可作为行业资讯，不要求存在销售介入窗口。

## 新增独立渠道

配置文件 `config_data/national_sources.json` 提供新增公开 HTML 来源，可以增删条目；每项含 publisher、url、kind，以及限定文章路径的 article_pattern。

- 掌链：https://www.i56r.com/
- 北自科技官网：https://www.bzkj.cn/Home.html
- 兰剑智能官网：https://www.blueswords.com/company-news_3
- LET 主办方：https://www.chinalet.cn/，采集官网网页自身调用的公开新闻接口。

以上入口经过普通 HTTP 访问核实。HTTP 200 仅代表请求成功；没有有效文章、关键词筛后为空、动态列表未解析、403 和超时分别记录，不能把网站可访问等同于有效来源。兰剑官网列表中的旧新闻仍受时效筛选，新增来源不保证每天有产出。

## 获取与解析

RSS 来源由顺序抓取改成最多四个列表并行，每个来源最多20秒。列表请求限制为2MB，原文补全每来源最多四篇，仅用于有行业相关性且缺少日期或摘要的文章。403/404 不做反复重试；一项来源失败不会让其他来源已经取得的结果丢失。

HTML 使用结构化节点分别获取标题、摘要、图片与文章卡片日期，避免把整张卡片拼成标题。无日期时有限读取正文的发布元数据/明确日期节点。列表和正文仅读取公开 HTTP(S) 地址，校验 DNS 结果且逐次检查重定向，拒绝本机和内网地址。网页修改时间、抓取时间、摘要中的未来活动时间不替代文章发布日期；日期冲突保持未知。

页面显示真实发布网站、文章类别和日期。采集入口另存 collection_url；skill_name 只表示采集渠道。转载或外链不会继承列表网站的官方发布身份。

## 国内页准入与排序

- 仓储、物流技术、设备、WMS/WCS、AGV/AMR 等直接相关内容优先；供应链及有关工业技术可作为背景资讯。
- 泛项目、土建招标、娱乐、招聘、股票涨跌等没有相关行业内容的文章排除。人形机器人在物流搬运等具体场景应用可保留。
- 主要依据行业相关度、来源性质、发布时间及具体摘要排序；图片不为文章提供质量加分。
- 已知发布日期超过15天的文章排除；日期未知仍可少量展示，并标“日期待核实”。未知日期且标题明确指向旧年份的条目排除。
- 同一发布方最多6条、未知日期最多4条。可通过 NATIONAL_SOURCE_MAX_COUNT 与 NATIONAL_UNKNOWN_DATE_MAX_COUNT 调整。
- 同一类别最多约三分之一，保证技术、案例、展会、政策等内容之间存在空间。没有足够合格内容时允许少于24条。
- 取消国内招投标最低四条的补位规则。优质招标、中标仍可入选，不因采购阶段结束而被排除。
- 跨网站相同报道去重优先保留原始发布；包号、数字和二次/重新/变更版本有区别的条目不按近似标题强行合并。带有一致公司、项目金额和相近发布日期的中标转载合并；地区、项目编号或公告版本冲突时保留为不同事件。中叉网/AGV网按同一发布方计算，而不是靠多个域名获得多个名额。

## 诊断与验证

每次全量刷新或国内局部刷新保存 `runtime/national_news_diagnostics.json`：

- 原始、相关、去重与入选四个阶段数量；
- 各实际域名入选数、来源分组、类别分布和日期未知数；
- 每个来源 HTTP/解析状态、解析数、返回数、正文补全数及失败码；
- 明确过滤原因及数量/多样性限制导致的未入选数；
- 缓存执行模式，避免把历史抓取记录当作当前成功抓取。

运行 `python -m unittest discover -s tests -v` 检查解析、日期、跨来源去重、数量约束、普通资讯与商机的筛选差异以及页面兼容。真实 HTTP 验证应保存在独立 runtime 检查文件；不触发企业微信发布或收费模型调用。

本轮验证：完整离线回归160项通过，Python编译、补丁格式和Compose配置检查通过。公开网站实采选出24条、来自12个链接域名；其中同一中标新闻的6条转载在进一步修复后离线回放合并为1条。该回放只使用已选样本，结果为19条，不代表从完整候选池重新选择只能得到19条。桌面1280和手机390像素宽度无横向溢出，完整日期不被拆行。实测仅进行公开HTTP读取，不使用付费LLM、不发送企业微信、不覆盖每日页面。
